# Saleha Sanober — Portfolio

A modern, responsive personal portfolio built with **HTML, CSS and JavaScript**.

## Included

- Modern dark + acid-green visual design
- Responsive mobile navigation
- Animated scrolling skill marquee
- Hero visual made entirely with CSS
- About, skills, experience, projects and contact sections
- GitHub Pages ready
- No framework required

## Personalize before publishing

Update these placeholders in `index.html`:

- `your.email@example.com`
- `https://github.com/`
- `https://www.linkedin.com/`
- Add your actual GitHub/project links

## Run locally

Open `index.html` in your browser or use VS Code Live Server.

## GitHub Pages

Create a GitHub repository, upload the three website files, then go to:

**Settings → Pages → Deploy from a branch → main → /(root) → Save**

Your live portfolio will then be available through the GitHub Pages URL.
